### Featured Project

#### [PBI Lineage Explorer](https://github.com/SNLSHETTY87/LineageVisualPBI)

A Power BI custom visual that renders an interactive, topological lineage graph showing how **Dataflows**, **Datasets**, and **Reports** connect across a Power BI tenant.

**Highlights:**
- Topological left-to-right dependency layout with S-curve edges
- Live search with workspace, dataflow, and report filters
- Click-to-highlight full upstream/downstream lineage
- Impact analysis panel and refresh status badges
- Normal & compact view modes with keyboard shortcuts
